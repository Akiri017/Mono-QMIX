Phase 2 — GlobalQMixer                                     INTENTIONAL DEVIATION
================================================================================

Scaffold                                   Actual
---------                                  ------
global_state_dim = max_total_vehicles      global_state_dim = n_agents * obs_dim
                 * obs_dim                                  = 32 * 65 = 2080
(all vehicles including background,        (controlled agents only)
 peak-padded)

Why it changed: batch["state"] = concatenated observations of the 32 controlled
agents only. Background vehicles do not have the obs_dim-dimensional observation
vector. Using controlled agents is simpler, RAM-cheaper, and consistent with
Mono QMIX. Corrected in Phase 4 when the batch field was inspected.

================================================================================
Phase 4 — Episode Data                                TWO INTENTIONAL DEVIATIONS
================================================================================

Deviation 1 — zone_assignments shape:

  Scaffold: (max_rsus, max_agents_per_rsu) — 2D assignment matrix
  Actual:   (n_agents,) — RSU id per agent slot, 1D

  The 1D format is cleaner for the scatter approach in train() and uses far
  less memory. The scatter reconstructs the 2D grouping on the fly.

Deviation 2 — rsu_agent_qs not stored in replay buffer:

  Scaffold: rsu_agent_qs pre-computed per timestep, stored in buffer
  Actual:   NOT stored. Computed inside train() via scatter_add_ from
            chosen_action_qvals.

  Saves ~0.5 GB at buffer_size=100. Storing it would be redundant given
  zone_assignments already encodes the mapping.
